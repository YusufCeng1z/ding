JavaScript toast notifications without a framework

The core of Ding does not need React or Svelte. If you have a plain JavaScript page, a Vue app, or any other setup, you can use the core package directly.

Try it:

Install

npm i @yusufceng1z/ding

Mount and show

import { mountToaster, toast } from '@yusufceng1z/ding';

      const unmount = mountToaster({ position: 'top-center' });

      toast.success('Saved');
      toast.error('Payment failed', { description: 'Card declined' });

mountToaster returns a function that removes the toaster again, useful if the page is torn down or the toaster should only exist on some routes.

Updating a long task

toast.loading returns an id. Pass it to toast.update to move the same toast through progress and into a result.

const id = toast.loading('Uploading photo…', { progress: 0 });
      toast.update(id, { progress: 0.6 });
      toast.update(id, { type: 'success', title: 'Photo uploaded', progress: null });

Options

Position and theme are set on mountToaster or later with toast.configure({ position, theme }). The full list of options is in the docs.

If you do use React or Svelte, the framework packages are thin wrappers over this one. See React or Svelte. The code is on GitHub.

Position, theme and sound

toast.configure({
  position: 'bottom-right', // top-left, top-center, top-right, bottom-left, bottom-center, bottom-right
  theme: 'dark',            // system, light, dark
  sound: true,
  volume: 0.5,
});

Restyle it with CSS variables

.tst-viewport {
  --tst-radius: 8px;
  --tst-bg: #1e3a8a;
  --tst-fg: #fff;
  --tst-success: #16a34a;
}

The playground generates this CSS for you.

Close and clean up

mountToaster returns an unmount function. Call it to remove the toaster. toast.dismiss(id) closes one toast and toast.dismiss() closes all of them.

Frequently asked questions

Do I need a framework?

No. @yusufceng1z/ding is plain DOM code with no dependencies. It ships ESM and CommonJS builds.

Is it safe to call during server rendering?

Yes. mountToaster does nothing when there is no document, so it is safe to import and call in code that also runs on the server.

Do I need to import CSS?

No. Styles are injected as one <style> element. If your Content Security Policy blocks inline styles, pass the page's nonce: mountToaster({ nonce }).

Is it accessible?

Yes: live regions, keyboard dismissal and reduced-motion support are built in. See accessible toast notifications.
