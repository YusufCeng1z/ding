Svelte 5 toast notifications

Ding has a Svelte package built for Svelte 5. It has no dependencies, needs no stylesheet, and the toast function works from components and from plain modules.

Try it:

Install

npm i @yusufceng1z/ding-svelte

It targets Svelte 5 only. If you are still on Svelte 4, this package will not work for you.

Mount it in the root layout

In SvelteKit that is src/routes/+layout.svelte. In a plain Svelte app, use your top-level component.

<script>
        import { Toaster } from '@yusufceng1z/ding-svelte';
        let { children } = $props();
      </script>

      {@render children()}
      <Toaster position="top-center" theme="system" />

Show a toast

import { toast } from '@yusufceng1z/ding-svelte';

      toast.success('Saved');
      toast.error('Payment failed', { description: 'Card declined' });

You can call it from a +page.ts load function, a store, an event handler, anywhere that runs in the browser. Call it on the server and nothing happens, since there is no page to show it on.

Behavior to know about

There is only ever one toast on screen. A new call changes the visible toast into the new message with a spring animation instead of adding a second one. That is the main difference from stacking libraries such as svelte-sonner, which I compare on the svelte-sonner alternative page.

Errors, loading toasts and toasts that have a button stay until dismissed. Everything else closes after five seconds. For loading states see loading toast, and for undo buttons see undo toast.

Position, theme and sound

Set them as props on Toaster, or call toast.configure from anywhere:

<Toaster position="bottom-right" theme="dark" />

toast.configure({ sound: true, volume: 0.5 });

Restyle it with CSS variables

Colors and corner radius are CSS variables, so they work the same in Svelte as in any other framework:

.tst-viewport {
  --tst-radius: 8px;
  --tst-bg: #1e3a8a;
  --tst-fg: #fff;
  --tst-success: #16a34a;
}

The playground lets you try the options and copy the CSS.

Frequently asked questions

Does Ding support Svelte 4?

No. @yusufceng1z/ding-svelte targets Svelte 5. For other setups the plain JavaScript package @yusufceng1z/ding works without a framework.

Do I need to import a stylesheet?

No. Ding injects its styles from JavaScript. If your Content Security Policy blocks inline styles, pass the page's nonce to Toaster.

How do I dismiss a toast from code?

toast.dismiss(id) closes one toast and toast.dismiss() closes all of them. Pressing Esc also dismisses.

Is it accessible?

Messages go through persistent live regions (errors are assertive, the rest polite), Alt + T moves focus into the toast, and motion respects prefers-reduced-motion. See accessible toast notifications.

Can I migrate from svelte-sonner?

Yes, the calls look alike. The svelte-sonner alternative guide lists what to check first.
