A svelte-sonner alternative for Svelte 5

svelte-sonner is a Svelte port of Sonner and it stacks toasts. Ding is a separate library built around one toast on screen that changes in place when a new message arrives.

Try it:

Install and mount

npm i @yusufceng1z/ding-svelte
<script>
        import { Toaster } from '@yusufceng1z/ding-svelte';
        let { children } = $props();
      </script>

      {@render children()}
      <Toaster position="top-center" theme="system" />

Use it

import { toast } from '@yusufceng1z/ding-svelte';

      toast.success('Saved');
      toast.promise(save(), { loading: 'Saving…', success: 'Saved', error: 'Failed' });

Should you switch

If you want one message at a time and no dependencies, yes, it is worth trying. If you need several toasts on screen at once, stay with a stacking library. Ding only supports Svelte 5.

The full Svelte setup is on the Svelte toast page, and the reasoning behind one toast at a time is on the Sonner alternative page.

Position, theme and sound

<Toaster position="bottom-right" theme="dark" />

toast.configure({ sound: true, volume: 0.5 });

Restyle it with CSS variables

.tst-viewport {
  --tst-radius: 8px;
  --tst-bg: #1e3a8a;
  --tst-fg: #fff;
  --tst-success: #16a34a;
}

Frequently asked questions

Is Ding a drop-in replacement for svelte-sonner?

The common calls look alike, but not every option exists in both. Check yours against the docs before switching.

Does Ding require Svelte 5?

Yes, @yusufceng1z/ding-svelte is for Svelte 5.

Do I need to import CSS?

No. Ding injects its styles from JavaScript.

Can I use the same library in React or Vue?

Yes. See React toast notifications, or the docs for Vue 3 and plain JavaScript.
