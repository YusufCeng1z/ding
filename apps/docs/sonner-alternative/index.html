A Sonner alternative that shows one toast at a time

Sonner is a good library and it stacks toasts. Ding makes a different choice: one toast on screen, and a new message turns the current toast into the new one. Which you want depends on your app.

Try it:

Why I made one toast at a time

In the apps I work on, a burst of events (save, then sync, then a failed request) produced a stack that covered the page and was harder to read than a single message. I wanted the latest message to win, with a visible transition so the user sees that it changed.

Pick Ding if

You want one message at a time. You update the same toast through loading, success and undo. You want zero dependencies and no CSS import. Or you use Svelte 5 or plain JavaScript as well as React.

Pick Sonner if

You need several toasts visible together, or you want a larger ecosystem and track record. Ding does not stack, and that is not going to change.

Switching

The calls look familiar. Render one Toaster, then:

import { toast } from '@yusufceng1z/ding-react';

      toast.success('Saved');
      toast.promise(save(), { loading: 'Saving…', success: 'Saved', error: 'Failed' });

Check the options you use against the docs before swapping, since not every option exists. Setup details are in React toast notifications. If you use Svelte, see the svelte-sonner alternative.

Ding is open source on GitHub. A star is the easiest way to say it was useful.

What Ding brings

  • Springs, not fades. Size, shape and text move on a spring solver, so interrupting an animation keeps its momentum.
  • No stylesheet and no dependencies. Styles are injected from JavaScript.
  • Four renderers. React, Svelte 5, Vue 3 and plain JavaScript share one core.
  • Rich content. Description, avatar, buttons, a progress bar, a countdown line and small trailing text.
  • Easy restyling. Colors and corner radius are CSS variables.

Frequently asked questions

Is Ding a drop-in replacement for Sonner?

The common calls look alike, but not every option exists in both libraries. Check the options you use against the docs before swapping.

Does Ding work outside React?

Yes. There are packages for Svelte 5 and Vue 3, and a plain JavaScript version. See svelte-sonner alternative and JavaScript toast notifications.

Does Ding need a CSS import?

No. Styles are injected from JavaScript.

Can I use Ding with shadcn/ui?

Yes, with one command. See the shadcn/ui toast guide.
